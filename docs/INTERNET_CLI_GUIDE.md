# Руководство по встроенному CLI для работы с интернетом (Agent Reach CLI)
## Исследования рынка, парсинг вакансий и сбор соревновательных данных

---

### 1. Назначение инструмента в проекте
В систему встроен мощный автономный сетевой агент-маршрутизатор **Agent Reach CLI**, поддерживающий обращение к 16 платформам (поисковики, профессиональные сети, джоб-борды, GitHub, аналитика).

Инструмент используется командой хакатона для:
1. **Анализа рынка IT-вакансий и зарплатных вилок**: парсинг реальных вилок зарплат в РФ по грейдам (Junior/Middle/Senior/Lead) для калибровки весов подбора.
2. **Исследования алгоритмических соревнований**: сбор архивов задач Чемпионатов и Кубков России по спортивному программированию для пополнения банка шаблонов.
3. **Мониторинга открытых репозиториев и бенчмарков**: поиск передовых подходов к Computerized Adaptive Testing (CAT) и алгоритмам ранжирования.

---

### 2. Проверка состояния каналов (Doctor)

Перед началом работы рекомендуется выполнить проверку доступности провайдеров:
```bash
agent-reach doctor --json
```

Вывод команды возвращает активные бэкенды для каждой категории запросов (Search, Career, Social, Dev).

---

### 3. Основные сценарии использования

#### 3.1. Исследование рынка труда и калибровка зарплатных вилок (Career)
Поиск актуальных требований работодателей к Middle/Senior разработчикам:
```bash
# Сбор данных по требованиям и вилкам в вакансиях
agent-reach search "вакансии Middle Python FastAPI зарплата вилка руб"
```

#### 3.2. Поиск алгоритмических задач и эталонных решений (Dev & Alg)
Поиск соревновательных задач ФСП и олимпиад по программированию:
```bash
# Поиск в GitHub открытых репозиториев олимпиадного программирования
agent-reach search "site:github.com спортпрог чемпионат россии алгоритмы"
```

#### 3.3. Исследование профессиональных дискуссий и отзывов (Social & Community)
Изучение болей соискателей при традиционном найме (для усиления презентации и питча):
```bash
# Анализ обсуждений на Хабре и профессиональных форумах
agent-reach search "site:habr.com обратный найм проблемы собеседований отклики вслепую"
```

---

### 4. Интеграция данных в платформу
Данные, собранные через Agent Reach CLI, импортируются в платформу следующим образом:
1. Сводные списки навыков дополняют справочник `seed/taxonomy.json`.
2. Структуры олимпиадных задач преобразуются в параметризованные шаблоны `seed/question_templates.json`.
3. Реальные медианы зарплат калибруют фактор $S_{salary}$ в ранжере `backend/app/services/matching/ranker.py`.
